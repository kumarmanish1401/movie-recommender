# Movie Recommender

A simple Python project that recommends similar movies based on their genres. Select a movie and optionally choose a genre to see up to five recommendations.

## Run the project

Run these commands from the project folder in PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Open http://127.0.0.1:5000 in the browser. Press Ctrl+C in the terminal to stop the application.
